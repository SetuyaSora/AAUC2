# AAUC2

学務システム「Active Academy Advance(AAA)」のトップページ(My Schedule)を、見やすい時間割ダッシュボードに置き換える Chrome 拡張機能です。出席登録・出欠の確認・欠席の警告などを、ひとつの画面にまとめます。

> **非公式ツールです。** AAA の提供元・各大学とは無関係です。利用は自己責任でお願いします。出席登録は、各大学の規則と担当教員の指示に従ってください。本ツールは出席パスワードを自動生成・保存・推測しません(パスワードは毎回、利用者自身が入力します)。

## 機能

**今日 / 週間 / 出欠 / メモ** の4タブ。

- **今日**: 日付・時計・授業中/次の授業のヒーロー(進捗バー付き)、授業のタイムライン、空き時間、予定
- **週間**: 時限×曜日のグリッド。授業ブロックをクリックすると、詳細ダイアログ(出席登録・出欠状況・メモ)が開きます
- **出席登録**: 元ページの「出席」リンクを経由して送信します。出席の受付状態(出席○/遅刻△/締切)のカウントダウンと、ブラウザ通知(授業前・受付開始・締切直前)
- **出欠の自動確認**: 「修学ポートフォリオ > 出欠調査状況表」を読み込み、各授業に出欠バッジ(○出席 ／欠席 △遅刻 ▽公欠)を表示します。出席送信後は、出欠表に反映されたかを自動で確認します。「出欠を確認」ボタンで手動確認もできます
- **欠席の警告**: 「全授業の3分の2以上の出席が必要」という規定に基づき、欠席の上限までの余裕を表示します。授業ごとに全回数が違うため、「出欠」タブで科目ごとに全回数を設定できます(未設定の科目は、これまでの調査回数から安全側に見積もった目安で判定します)
- **ログイン切れの警告**: セッション(最後の通信から20分)の残り時間を推定して表示し、切れそうなとき・切れたときに警告します
- **メモ**: 科目全体のメモと、その回のメモ。Chrome の同期で他の PC とも共有されます
- **カレンダーへ書き出し(.ics)**: 時間割を Google カレンダー・iPhone・Outlook などに取り込めます
- テーマ切替(自動/ライト/ダーク)、アニメーション、`Alt+A` で開閉、`Esc` で閉じる

## インストール

1. Chrome で `chrome://extensions` を開き、右上の「デベロッパー モード」を ON
2. 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択
3. AAA のトップページを開く

`manifest.json` の `matches` は `https://*.ac.jp/aa_web/portal/*` と広めにしてあり、実際に動くのは、`content.js` と `early.js` の先頭にあるホストの判定(`aaaportal.*.ac.jp`)に合うサイトだけです。**自分の大学のポータルのホスト名が違う場合は、この判定(2か所とも同じ値)と、`manifest.json` の `matches` を書き換えてください**。時限の時刻(`content.js` の `PERIOD_OF`)、出席受付の秒数(`WIN_ON_TIME` / `WIN_LATE`)、欠席の規定(`attendanceRisk`)は、ある大学の学生便覧に基づく値です。ご自身の大学の規定に合わせて調整してください。

## デモ(ポータルへの接続なし)

`demo.html` をブラウザで開くと、モックデータで UI を確認できます。デモの時計は 13:38 から進み(`demo.html?time=13:42` のように時刻を指定できます)、授業は実際の時限(09:10 / 11:00 / 13:40 / 15:30 / 17:20)で作っています。出席パスワードは、`1234` で「登録完了」、`0000` でモーダルが閉じるだけのケース、それ以外はエラーを試せます。授業名・教員名はすべてダミーです。

## プライバシー・権限

- 外部のサーバーには何も送信しません(外部CDN・解析なし)。
- 拡張機能の権限は `storage` のみです(メモと設定の保存・Chrome 同期用)。対象のポータル以外のサイトでは動作しません。
- メモ・設定は、ブラウザの localStorage と Chrome の同期ストレージに保存されます。パスワードや個人情報は保存しません。

## 実装上の注意(ポータルの挙動)

- ポータルはサーバー側で画面遷移を検証しています。**出欠表のページ(`rz0030.aspx`)を直接取得すると「画面遷移が不正です」エラーになり、セッションが切れます。** そのため、メニュー「修学ポートフォリオ」への正規の遷移(トップのフォーム送信)を経由してから取得しています。同様の理由で、出席の受付時間帯とパスワード画面の表示中は、出欠表の自動取得を止めています。
- セッションが切れても、ページの再読み込みで(シングルサインオンのログイン状態から)自動で復帰できます。ログイン状態の確認は、トップページの再取得だけで行い、常時のキープアライブはしません。
- 週の移動などでページ全体が再読み込みされる間は、元のポータル画面が一瞬見えることがあります(仕様上の制限です。`early.js` が背景色で覆って軽減しています)。
- 出欠表は1ページに15回分のマスまでです。15回を超える授業は、集計値(調査/出席/欠席の回数)で判定し、マスが見えない旨を表示します。

## 検証状況

- UI・出席送信の流れ・出欠の照合・警告・同期・`.ics` は、実物を模したモック(`demo.html`)と、ポータルの実際の HTML 構造の調査で確認しています。
- 次の点は、**実際の授業中では未検証**です: 出席リンクの実物、出席送信後の「登録完了」画面の文言、出欠表への反映のタイミング、15回を超える授業のページ送り。うまく動かない場合は、Issue でご報告ください。
